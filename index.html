Summary

I design and build documentation systems, and the AI agents that write docs on top of them. At Union.ai I built the documentation platform for Flyte 2 and Union from the ground up, then built an agent that writes and maintains docs using it.

Before that I led documentation rewrites at Sonar and Unblu and built Adobe's publishing platform for AEM documentation. I co-authored and edited the Java Content Repository specification (JSR-170 and JSR-283), the foundation of Adobe Experience Manager. Over 25 years I have worked as a software engineer, API architect, specification author and documentation lead.
